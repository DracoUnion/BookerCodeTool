# BookerCodeTool 代码结构

iBooker/DracoUnion 代码相关大模型 Agent 工具。

命令行入口两个：`BookerCodeTool` 与 `code-tool`，均映射到 `BookerCodeTool.__main__:main`（见 pyproject.toml 的 `[project.scripts]`），即 `python -m BookerCodeTool` 也可直接运行。自带子命令：`doc`（代码添加注释）、`book`（代码→书籍）、`check-book`（书籍校验）、`re`（逆向工程智能体，IDA / x64dbg / x32dbg）、`pentest`（渗透测试智能体）。

代码全部位于 `BookerCodeTool/` 包内，按职责分为六类模块：

## 1. 入口与命令注册

+ `__main__.py` — 唯一 CLI 入口。构建顶层 `argparse` 解析器（含 `-m/--model`、`-k/--key`、`-H/--host`、`-r/--retry`、`-tm/--temp`、`-D/--debug` 等公共 LLM 参数），注册 `doc`、`book`、`check-book`、`re`、`pentest` 五个子命令，最后按 `args.func(args)` 派发。
+ `__init__.py` — 包元信息（`__version__` = 2026.3.25.0，作者 wizardforcel，SATA 协议）。
+ 每个子命令模块暴露 `reg_subparser(subparsers)`，在其中通过 `subparsers.add_parser("<命令名>")` 注册子命令并指定 `func=xxx` 入口函数；`__main__.py` 中逐一调用注册。

## 2. 书籍生成命令（book / check-book）

+ `book.py` — `book` 与 `check-book` 子命令注册及编排器：`BookMixin` 共享步骤方法；`BookOrchestrator` 实现“代码 → 书籍”主流程（大纲→代码/类细节→正文生成）；`BookCheckOrchestrator` 实现书籍校验器；`book()` / `book_check()` 为两个入口函数，`reg_subparser` 同时注册 `book` 与 `check-book` 两个子命令。
+ `book_agent.py` — `BookAgent` 与 `BookCheckAgent` 智能体类：接收 `args`，每个大模型调用为其中一个方法，复用 `util.render_prompt`、`json_dump_model`，经 `openai.call_llm_retry` 调用 LLM，并传 `parse_output` 回调（内部用 `ext_cont_block` / `ext_code_block` + `parse_obj_as` 解析）；`expand_stars` 展开文件模式。
+ `book_models.py` — 代码→书籍的 Pydantic 模型：`PartClusResult`、`FuncExtResult`、`ClsExtResult`、`ClsFuncExtResult`、`CodeDescItemResult`、`OutlineNode/Chapter/PartResult`、`SrcAnlsDetail*`/`RestDetail*`、`Detail` 等，字段均带 `Field(..., description=...)`。
+ `book_pmt.py` — `book`/`check-book` 提示词模板，定义为全局多行字符串常量 `{XXX}_PMT`（中文，JSON 输出用三反引号包裹）。

## 3. 代码注释命令（doc）

+ `doc.py` — `doc` 子命令：`DocOrchestrator` 给代码目录/文件批量添加注释（源自 code2doc），`process_file_safe` 多线程安全处理单文件，`doc_handle` 入口，`reg_subparser` 注册。
+ `doc_agent.py` — `DocAgent` 智能体：逐类/逐文件调用 LLM 生成注释并解析为结构化模型。
+ `doc_models.py` — 注释提取的 Pydantic 模型：`OverViewClassResult`、`OverviewResult`、`VarExtResult`、`FieldExtResult`、`VarFieldExtResult`。
+ `doc_pmt.py` — `doc` 命令提示词模板。

## 4. 逆向工程命令（re）

+ `re.py` — `re` 子命令：`ReOrchestrator` 逆向工程工作流编排（函数定位等），`check_avail` 检查 IDA / x64dbg 环境是否可用，`re_handle` 入口，`reg_subparser` 注册，`parse_final` 解析最终报告。
+ `re_ida.py` — `IdaClient`：IDA Pro 自动化客户端（通过 idapro 库交互），`IdaError` 异常。
+ `re_xauto.py` — `XautoClient`：x64dbg / x32dbg 调试器自动化客户端，`XautoError` 异常，`_hexdump` 等十六进制工具。
+ `re_tools.py` — `ReTools(ToolsMixin)`：逆向开放工具调用循环，将 IDA/xauto 操作封装为 `tool_*` 方法，`_ida_schema` / `_xauto_schema` 构造 function-calling Schema。
+ `re_models.py` — 逆向 Pydantic 模型：`ReState`、`ReFinding`、`ReFinalReport`、`McpServerStatus`、`AnalysisResult`、`MCPToolResult`。
+ `re_pmt.py` — `re` 命令提示词模板。

## 5. 渗透测试命令（pentest）

+ `pentest.py` — `pentest` 子命令：`PentestOrchestrator` 按工作流步骤执行渗透测试技能（技能按工作流拆分为步骤工具 + bash/文件/打印/询问用户），`pentest_handle` / `list_skills` 入口，`reg_subparser` 注册，`parse_final` 解析最终报告，`_sanitize_findings` 清洗发现项。
+ `pentest_tools.py` — `PentestTools(ToolsMixin)`：内置渗透技能的步骤工具，`builtin_skills()` 与 `step_tool_map()` 输出“技能 → 步骤 → 工具名”映射。
+ `pentest_models.py` — 渗透测试 Pydantic 模型：`PentestState`、`SkillInfo`/`SkillStep`/`SkillCommand`/`SkillGuide`/`SkillStepGuide`、`PentestFinding`/`PentestFinalReport`、`AskUserResult`。
+ `pentest_pmt.py` — `pentest` 命令提示词模板。

## 6. 共享基础设施

+ `util.py` — 通用工具函数，跨命令复用：文本/Markdown 解析（`split_md_lines`、`group_chunks`、`fix_lists`、`reform_paras_mdcn`）、代码块提取与还原（`repl_code_block`、`rec_code_block`）、文件读写（`read_text`/`write_text`、`read_yaml_model`/`write_yaml_model`）、模型序列化（`json_dump_model`/`json_load_model`）、PDF 文本提取（`read_pdf_text`）、文本相似度（`ngram_jaccard`/`ngram_coverage`）、`md5`/`extname`/`to_kebab` 等路径与摘要工具。
+ `openai.py` — LLM 客户端层：`OpenAIClient` 类封装 `request_retry` / `call_llm` / `call_llm_retry`；`ToolsMixin` 工具型命令混入；`base_schema`/`func_schema`/`params_schema`/`model_schema`/`model_list_schema`/`str_list_schema`/`str_str_map_schema` Schema 构造助手；`dispatch_tools` 按模型返回的 tool call 分发到工具方法。

## 7. 关键约定（来自 AGENTS.md）

新增子命令遵循固定范式，命名转换 `sub-cmd` → `sub_cmd`：

+ 提示词 → `<sub_cmd>_pmt.py`；模型 → `<sub_cmd>_models.py`；智能体 → `<sub_cmd>_agent.py`；编排器 → `<sub_cmd>.py`。
+ 若为工具型命令（开放循环），则不建 `_agent.py`，改建 `<sub_cmd>_tools.py`，编排器 `run()` 调 `call_llm_with_toolcall_retry()`。
+ 在 `<sub_cmd>.py` 写 `reg_subparser(subparsers)`，再到 `__main__.py` 中调用它注册。

## 8. 外部依赖

+ Python：`openai`、`httpx`、`requests`、`pyyaml`、`pydantic`、`json_repair`、`pymupdf`、`pillow`、`tqdm`、`pyturndown`、`ctx-compact`（见 `requirements.txt`）。
+ 可选外部工具：IDA Pro（`re` 命令，`idapro`）、x64dbg（`re` 命令，`x64dbg-automate`，见 `[project.optional-dependencies]` 的 `re` 组）。
+ 环境变量：`OPENAI_API_KEY`、`OPENAI_BASE_URL`、`OPENAI_CHAT_MODEL`、`OPENAI_VIS_MODEL`、`OPENAI_TTI_MODEL`、`EMB_MODEL_PATH` 等，均可被命令行参数覆盖。
